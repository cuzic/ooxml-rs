# O3 expected values (LibreOffice recalculation)

`expected.tsv` holds LibreOffice's recalculated cell values for the O3 inputs and outputs
(ADR-0003 §7.1). `tests/phase1_o3.rs` (crate `ooxml-xlsx`) reads it.

- Generated by the `o3-recalc` workflow, run
  <https://github.com/cuzic/ooxml-rs/actions/runs/43821205800> (artifact
  `o3-expected-a46b295e312d363697f0370dbf8dc3c4547af6a7`), with
  `spikes/xlsx/o3_recalc.py`. The header records the LibreOffice version (25.2.7.2), the commit,
  locale, TZ and the `Cargo.lock` SHA-256. The canary was recalculated.
- SHA-256 of `expected.tsv`: `1859f377fb4708e43a711b378f98e132f140e43d4c7f610f987e6b716309689a`.
- Each row records an FNV-1a hash of its workbook. The test fails with "input/output changed since
  the data was generated" when the O3 inputs change. To regenerate, dispatch the workflow on the
  branch and commit the artifact's `expected.tsv` here.
- Licence: these are facts computed from the Apache-2.0 POI fixtures (`../poi/NOTICE`) and from
  the synthetic workbooks. LibreOffice's MPL-2.0 does not cover its output.
